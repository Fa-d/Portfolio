## Updating Site Content

All content lives in JSON files under `public/data/` (strings, skills, career, education, projects, products, open-source contributions, articles, notes). Edit those files directly, preview with `npm run dev`, then commit and push to `master` — the GitHub Actions workflow builds the site and deploys it to GitHub Pages (sadakat.dev).
